# research/ Исследовательские планы

Каталог содержит планы, подготовленные до написания кода и до написания научных
текстов. Планы описывают, что именно строится, по каким определениям и с какими
проверяемыми критериями приёмки. Они остаются первоисточником формулировок:
научный текст и реализация обязаны им соответствовать, а расхождение считается
дефектом.

## Порядок чтения

Документ 01 задаёт понятийный аппарат, на который опираются документы 02 и 03.
Документ 02 определяет данные, которые документ 03 автоматизирует. Документ 99
читается после 01–03: он содержит возражения, и у каждого из них проставлено,
разрешено оно или остаётся открытым.

## Отношение к действующему состоянию

Планы правились дважды. Первый раз при утверждении, когда часть формулировок
изменилась по итогам разбора 99. Второй раз при перестройке проекта в портал,
когда изменились сами основания:

- **Состав схемы.** Сумма по таблицам групп даёт двадцать шесть измерений, а не
  двадцать два, как говорил ранний итоговый абзац плана 01. За основу взяты
  таблицы; число закреплено проверкой в коде.
- **Хранилище реестра.** План 02 предлагал каталог файлов, промежуточное решение
  вводило базу данных. Действующее решение — версионируемые файлы в `data/`
  (`governance/DECISIONS.md`, ADR-004).
- **Граница «текущее и перспективное».** План 02 показал, что она не
  выдерживается. Действующее решение отменяет её полностью: есть одна непрерывная
  шкала созревания (ADR-007).
- **Форма главного представления.** План 03 описывал радиальную раскладку;
  действующее решение — двумерная карта «зрелость и внимание» (ADR-008).
