# Code of conduct

## The short version

Disagree with the claim, not with the person making it.

This project is about checking things. Being told you are wrong, with evidence,
is the point of it — for contributors and maintainer alike. That only works if
the disagreement stays about the evidence.

## Expected

- Argue from sources. "This is wrong because the paper says X on page 4" is a
  contribution; "this is wrong" is not.
- Assume the other person read something you did not.
- Accept correction the same way you offer it.

## Not accepted

- Personal attacks, harassment, or discrimination of any kind.
- Sustained disruption: reopening settled questions without new evidence.
- Publishing others' private information.

## Enforcement

Report conduct problems to the maintainer via
[GitHub](https://github.com/laputski). Reports stay confidential.

Responses range from a request to change tone, through editing or removing a
contribution, to blocking. The maintainer decides and will say which rule was
broken and why.
